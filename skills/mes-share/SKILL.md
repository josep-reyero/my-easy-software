name: mes-share
description: Share chosen dashboards of a my-easy-software project with other people with "mes expose" (Cloudflare Pages, Netlify or Vercel; only named people, anyone with the link, or public). Use when the user wants to show a dashboard to a friend, family, a coach or the public, or to stop sharing it.

# Share dashboards

Run `mes guide share` and follow it. Always show the user the confirmation question mes returns
(which dashboards and data become visible, and to whom) and let them answer it; never answer it
for them. Start with `--dry-run`.
